This is the complete repository of our group project: Will.y!  
Will.y is an open-source solution based on Ethereum for secure, transparent and accessible inheritance of cryptoassets.  
Contents:
- Willy_REPORT = full report of the Will.y project
- Willy_PRESENTATION = pptx presentation
- Willy_DEMO = Solidity code of WillyVault
- Willy_WALKTHROUGH = notebook with in-depth explanation of the smart contract code and technical features.
- Willy_SHOWCASE = Mock usage of WillyVault on Remix, see here -> https://www.youtube.com/watch?v=4x-5J0ieB0o
